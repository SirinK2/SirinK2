### Featured

#### [GenomeTrack](https://github.com/SirinK2/GenomeTrack) — backend
`ASP.NET Core 9` `PostgreSQL` `EF Core` `Docker` `Flutter`

Sample chain of custody for a genomics lab. Most systems treat a custody trail as a log table —
rows anyone with database access can quietly edit. Here every event is hash-linked to the one
before it, so editing history is detectable and the API names the exact record that changed.

Clean Architecture, 28 unit tests, CI, and a Flutter web client that renders what the API
permits and nothing more.
